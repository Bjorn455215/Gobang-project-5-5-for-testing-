# 復古風格五子棋: 手勢操作 (5x5)

本專案結合 **電腦視覺** 與 **人機互動** 的五子棋系統。無需觸碰滑鼠或鍵盤，只需直接在攝影機前透過「捏合」與「張開」的手勢，實現虛擬棋子的抓取、移動與落子。

## 專案功能

* **手勢控制**：
    * **生成棋子**：於左右兩側生成區張開手掌即可產出棋子。
    * **捏合抓取**：模擬現實生活中的捏取動作（大拇指與食指靠近）。
* **復古風**：利用的「木質、宣紙、硃砂」色調參數，並搭配文字描邊效果，確保在背景下清晰可見。
* **自動化邏輯**：
    * **格點吸附**：棋子放開後會自動校準至最近的格點中心。
    * **勝場統計**：自動累計黑白雙方的勝利次數。
    * **防重疊系統**：落子時會自動判斷該位置是否已有棋子。
* **勝負自動判定**：內建 5x5 掃描演算法，偵測到連線後自動顯示勝利者並於 5 秒後重置棋盤。

---

## 技術規格

* **語言**：Python 3.9
* **核心函式庫**：
    * `OpenCV`: 負責影像捕捉與圖形 UI 繪製。
    * `cvzone` & `MediaPipe`: 處理 21 個手部關鍵點即時追蹤。
    * `NumPy`: 管理 5x5 棋盤邏輯矩陣。

---

## 環境安裝
確保已安裝必要的函式庫：
```bash
pip install opencv-python cvzone numpy
```
